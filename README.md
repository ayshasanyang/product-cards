# Product Cards

A simple product cards layout built using HTML and CSS

## Live Demo

Click [Here](https://ayshasanyang.github.io/product-cards/) to view the page

## Technologies Used

- HTML
- CSS

## How to Run Locally

1. Download or clone the repository

```bash
git clone https://github.com/ayshasanyang/product-cards.git
```

2. Navigate to the project folder
3. Open the project files in your vscode or any code editor of your choice
4. Open the index.html file in your web browser
